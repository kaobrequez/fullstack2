# La Esquina del Sabor

## Descripción

La Esquina del Sabor es un sitio web desarrollado para la evaluación de Desarrollo Fullstack II.
El proyecto presenta el menú digital de un local de comida rápida (hamburguesas, completos y otros productos), incluyendo un sistema de registro e inicio de sesión de usuarios con validaciones en el formulario.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* [Bulma](https://bulma.io/) (framework CSS)

## Estructura del proyecto

* `index.html`: página principal del sitio, con el catálogo de productos.
* `pages/login.html`: formulario de inicio de sesión.
* `pages/registro.html`: formulario de registro de usuario.
* `pages/contacto.html`: página de contacto.
* `css/style.css`: estilos y diseño visual del sitio.
* `js/script.js`: validaciones del formulario de registro (correo, teléfono y edad).
* `img/logo/`: imágenes del logo del sitio.
* `img/productos/`: imágenes de los productos del menú.
* `wireframe/v1.png`: wireframe inicial del diseño del sitio.

## Características

* Página principal con catálogo de productos y navegación.
* Formularios de inicio de sesión y registro.
* Validaciones en JavaScript del formulario de registro:
  * Solo se aceptan correos de los dominios `gmail.com`, `outlook.com` y `duocuc.cl`.
  * El número de teléfono debe tener formato chileno (ej: `+56912345678`).
  * El usuario debe ser mayor de 18 años para poder registrarse.
* Mensajes de confirmación y error mostrados en pantalla, con redirección automática al inicio.
* Diseño adaptable a distintos tamaños de pantalla (responsive, gracias a Bulma).
* Navegación mediante hipervínculos entre las distintas páginas del sitio.
